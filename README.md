# Meridian — онлайн-курсы

Лендинг платформы онлайн-курсов (RU): live-карта навыков, поиск с подсказками, заявки.

## Stack
TanStack Start · React 19 · Vite 8 · Tailwind v4 · Nitro (Vercel)

## One-click deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fvestissivan%2Fmeridian-courses)

Or: open https://vercel.com/new and import `vestissivan/meridian-courses`.

- **Build command:** `npm run build`
- **Install:** `npm install`
- Output is generated by Nitro (`vercel` preset) into `.vercel/output`

## Local

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npx vite preview --host 0.0.0.0 --port 8080
```

## Notes
- Images live in `public/images/`
- Application form state is client-side (localStorage)
